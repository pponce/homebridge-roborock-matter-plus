Suggested title: **Exclude correlated MQTT session silence from method breaker counts**

## Replacement PR description

A connected MQTT session can stop delivering replies across an account. Counting those failures against each method can disable healthy methods for six hours.

This change exempts only reads with qualifying request evidence and cross-robot correlated silence, using a structured error marker. A single robot's silence still counts toward its method breaker. The default three-timeout recovery rule remains separate and active.

The integration tests drive the real recovery callbacks alongside the breaker and verify one restart, strict two-robot exemption and no double counting. Subscription failures cannot manufacture a qualifying observation. Documentation describes the lasting behavior without series numbering.

Based directly on v3.39.0. The unrelated TCP-probe test change is split out. Refs #27.
